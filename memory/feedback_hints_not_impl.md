metadata:
  type: feedback

When the user asks "how to do X", give hints and pointers (concepts, relevant API names, approach) rather than writing the code for them.

**Why:** User is intentionally learning Drake (and likely other frameworks) and wants to build understanding, not just receive working code.

**How to apply:** For any Drake/robotics coding question, explain the relevant API, the conceptual approach, and what to look up — but do not write or edit the implementation unless explicitly asked to.
